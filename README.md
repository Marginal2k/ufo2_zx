# НЛО-2. Дьяволы бездны — исходные коды для ZX Spectrum 128K

Стратегия 1996 года для ZX Spectrum 128K (автор — Вячеслав Медноногов, Copper Feet). Этот репозиторий — авторский архив
исходников (`UFO2_SRC.ZIP`, ассемблер ASM80, CP866), приведённый к современному виду:

* исходные тексты в UTF-8, собираются [sjasmplus](https://github.com/z00m128/sjasmplus);
* ресурсы — обычные редактируемые файлы (PNG, SCR, UTF-8 тексты, таблица свойств тайлов);
* утилиты автора (Turbo Pascal, Borland C++) переписаны на Python;
* **защиты нет**, игра целиком на одном стандартном диске TR-DOS (`build/ufo2.trd`);
* вся работа с диском — в одном файле [src/game/disk.asm](src/game/disk.asm).

Подробности: [docs/NOTES.md](docs/NOTES.md).

## Сборка

Нужны Python 3.9+ с Pillow и sjasmplus 1.20+ (проверено на 1.23). Для упаковки используется `tools/bin/zx0.exe`
(если его нет — медленный порт на Python из `tools/third_party/zx0`).

```bash
python build.py
```

Результат — `build/ufo2.trd`. Первая сборка упаковывает около 110 файлов (несколько минут), дальше работает кеш `build/cache`.

## Отличия от релиза 1996 года

* Нет защиты: нестандартных дисков, проверок ключевой таблицы и контрольных сумм, «ловушек» при их несовпадении.
* Один диск TR-DOS вместо двух; сохранение — в файл `ufo2save` на том же диске.
* Таблицы прерываний IM2 перенесены выше `#8000`: на фирменных 128K/+2 регистр I, указывающий в `#4000–#7FFF`, вызывал «снег».
* Сжатие ZX0 вместо авторского LZ-упаковщика LPC: данные на диске 400 КБ вместо 470 КБ.
* Чит «без 3D-боя» теперь задаёт вопрос Y/N, а не ждёт ответа молча.

## Читы автора

* **Без 3D-боя.** На запросе «Вставьте диск 2 и нажмите ENTER» держать **J** и нажать **ENTER**. При перехвате НЛО
  вместо боя кораблей сразу появится вопрос «Начать операцию по захвату НЛО (Y/N)?».
* **Мгновенная победа в тактическом бою.** Если на складе ровно **31 гарпун и 31 торпедный аппарат**, в начале
  боя все пришельцы убиты или парализованы (`VZLOM`, src/game/xlin.asm).
* В исходниках есть ещё два отладочных переключателя: `xHACK = #7F` открывает всю карту боя, `xHAC2 = #D6` — то же, что первый чит.
