# НЛО-2: устройство проекта

## Каталоги

| Каталог | Что в нём |
|---|---|
| `src/game/` | игра. `main.asm` — точка сборки и карта памяти; `xcom.asm` — ядро, прерывание, клавиатура; `xlid`, `xlib`, `xlie` — резидентные библиотеки; `xlin`, `xlim`, `xlik` — тактический бой; оверлеи `xlix` (меню), `xlic` (карта мира), `xlif` + `disk.asm` (ландшафты, диск), `xlesha` (3D-бой кораблей); `xli1` — начальная установка; `xpage` — содержимое страниц 128K |
| `src/boot/` | загрузчик TR-DOS |
| `src/title/`, `src/manual/`, `src/intro/`, `src/ending/` | заставка с меню, инструкция, вступительный ролик, концовка |
| `src/lib/dzx0.asm` | распаковщик ZX0 (общий для всех программ, метка `DELPC`) |
| `src/original/` | исходники 1996 г., которые в сборку не входят: загрузчики защищённых дисков, дисковый слой с защитой (`xiod.asm`), ленточная версия, редактор карт, мышь, распаковщик LPC |
| `assets/` | ресурсы: `gfx/` (PNG), `screens/` (SCR), `maps/` (карты 8192 байта), `text/ru/` (UTF-8), `tiles.txt` (свойства тайлов), `fonts/`, `music/`, `tables/` |
| `tools/` | `mkdata.py` (ресурсы → формат игры), `gfxconv.py`, `textconv.py`, `zx0.py`, `trd.py`; разовые: `a80conv.py` (ASM80 → sjasmplus), `import_archive.py` (архив → assets), `extract_ref.py`, `fdi.py`, `lpc.py` (разбор оригинальных дисков); `emu/` — тесты в эмуляторе ZX-M8XXX |
| `archive/` | архив автора без изменений |
| `reference/` | образы оригинальных дисков для сверки (в репозиторий не входят) |

## Сборка по шагам (`build.py`)

1. `tools/mkdata.py`: `assets/` → `build/data/`.
2. Собирается концовка; 73 ресурса упаковываются ZX0 и получают место на диске → `build/disk_layout.inc`.
3. Собирается игра (`src/game/main.asm`); четыре оверлея упаковываются в страницу 0, их адреса вписываются в `OVLTAB`.
4. Собираются заставка, инструкция, интро; файлы загрузчика упаковываются → `build/boot_layout.inc`; собирается загрузчик.
5. Образ `build/ufo2.trd`.

## Диск

Обычный TR-DOS, 92 файла. Ресурсы игры (`m2`…`up20`) видны в каталоге как отдельные файлы, но игра читает их
по позиции (таблица `RESTAB`), поэтому после изменения ресурсов нужна пересборка, а не копирование файлов.

Игра держит код в области экрана и системных переменных, поэтому вызвать `#3D13` из неё нельзя. Как и в 1996 году,
секторы читаются фрагментами ПЗУ TR-DOS 5.03 через `#3D2F` (`#2A53`, `#3EF5`, `#2090`, `#2FC3`, `#3FCA`, `#2F5F`).
Загрузчик, пока системные переменные целы, пользуется обычным `#3D13`. Номер дисковода загрузчик передаёт игре (`DSKDRV`).

## Защита (убрана)

* нестандартные форматы дисков (секторы 512 и 1024 байта с номерами `#F4…#FD`), «царапина» на диске 2 (`PROTEC`);
* ключевая таблица `TAB100`/`BUF100` и проверки `CHECK3`, `CHECK4`, `CHECK6`, `CHECK7`;
* контрольные суммы кода `CRC2`, `CRC3`, `CRC4` (`CHK_2`, `CHK_3`, `CHK_4`), считавшиеся в `START1`;
* при несовпадении игра портила себя: не тот ландшафт, обмен кода боя, выход в меню, порча сохранения.

В архиве автора проверка диска уже была отключена (`RET` в `TR_SEC`), остальные проверки работали.
Релиз получался в три этапа: сборка, запуск с простановкой сумм, снимок памяти. Теперь этого нет — игра
собирается за один проход и при первом запуске сама раскладывает оверлеи (`START1`).

## Память и прерывания

Карта памяти — в начале `src/game/main.asm`. Таблица векторов IM2 (257 одинаковых байт) в игре стоит на `#8E00`
(I = `#8E`), переход на обработчик — на `#8D8D`; область вне зоны обмена, поэтому в памяти всегда.
В 1996 году таблица была на `#4100` (в заставке и интро — на `#7100`). На фирменных 128K/+2 ULA при I в диапазоне
`#40–#7F` портит изображение («снег»); на +2A/+3 и клонах эффекта нет.

Стек на карте мира — `#4000–#403F` (46 байт в 1996 году, теперь 62: распаковщик ZX0 берёт на слово больше).

## Сжатие

Формат блока: слово длины, затем поток ZX0 v2. Все вызовы — `DELPC` (HL — поток, DE — куда).
Автор в 1996 году паковал своим LZ-упаковщиком LPC (исходника в архиве нет, только `XLPC.EXE`); формат описан
и реализован в `tools/lpc.py` — он нужен только для разбора оригинальных дисков.
Распаковка «на месте» используется в игре для страниц энциклопедии и концовки и в загрузчике для программ с `#7000`;
`build.py` проверяет, что она безопасна.

## Что в архиве новее релиза

Четыре файла архива отличаются от релиза: набор ландшафта `xm11`, три картинки энциклопедии (страница 6),
один байт карты `xl18`, лишний пробел в `xword.txt`. В `assets/` взяты релизные версии, архивные лежат рядом
с суффиксом `_archive`.

## Тесты в эмуляторе

```bash
python tools/emu/run_emu.py play name=t "steps=w500,K2,w900,kEnter,w300,s:map"   # сценарий: ожидания, клавиши, снимки
python tools/emu/shots.py t                                                      # снимки → build/emu/t_*.png
python tools/emu/run_emu.py disktest name=disktest                               # сохранение и ресурсы
python tools/emu/run_emu.py battle name=battle pc=<адрес "LD A,(xHAC2)" из build/game/main.lst>
```

Путь к эмулятору — переменная `M8XXX_DIR` (`tools/emu/serve_emu.py`). Сценарии иногда срываются на старте
(игра не успевает запуститься) — тогда запуск нужно повторить.
